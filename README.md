# ML Lab на Rust и Leptos

Браузерная лаборатория для лекции. Leptos отвечает за интерфейс, а модели, генерация данных, разметка и метрики выполняются в Rust, скомпилированном в WebAssembly. Приложению не нужны сервер вычислений, аккаунты и внешние запросы во время работы. Исходная лаборатория находится рядом в `../sine-ml-lab`.

## Запуск

Нужны Rust 1.89 или новее, установленный целевой профиль WebAssembly и Trunk. Сборка проверена с Trunk 0.21.14. Версии зависимостей закреплены в `Cargo.lock`.

Из папки `experiments/ml-lab-leptos`:

```sh
rustup target add wasm32-unknown-unknown
trunk serve --locked
```

Открой [http://127.0.0.1:8080](http://127.0.0.1:8080). Trunk при необходимости загружает CLI wasm-bindgen версии, указанной в `Trunk.toml`. Для сборки без сети зависимости Cargo должны быть в кэше, а подходящий CLI должен быть доступен Trunk. Если окружение задаёт `NO_COLOR=1`, а Trunk 0.21.14 отказывается запускаться, используй `env -u NO_COLOR trunk serve --locked`.

## Релизная сборка

```sh
trunk build --release --locked
```

Размещай весь каталог `dist/` в корне статического сайта, включая сгенерированные JS и WASM. Для подкаталога передай Trunk соответствующий `--public-url`. Сервер должен выдавать WASM с типом `application/wasm`. Для локального просмотра релизной сборки можно запустить `python3 -m http.server 8080 --directory dist`.

## Что перенесено

- Полиномиальная регрессия, kNN, дерево, случайный лес, RBF, нейросеть и гауссовский процесс.
- От 8 до 200 обучающих точек, детерминированный seed, шум, искусственные ошибки измерения и ручная разметка. Пометки исключаются перед свёрткой по фазе.
- Отдельные переключатели линий, тестовых точек и сравнений. Стартовый экран соответствует лекционному сценарию: 24 точки, шум ±0,50, seed 72, три выброса силой 3, полином степени 4. Линии, период и сравнения включаются вручную.
- Настройки методов, три пресета, график ошибки, схема предсказания, коэффициенты и правила. Дерево показывает четыре уровня и полный путь текстом. У нейросети показаны слои и активации, доступен пошаговый просмотр.
- Обучение Adam небольшими порциями, включая кнопку «+100 эпох». Снимок периодической сети загружается для 24 точек, шума 0.12, seed 42, выключенных выбросов и архитектуры 1→32→1 с исходными параметрами оптимизатора.

Схемы и таблицы заново оформлены в Leptos. Для полинома формула представлена в базисе Чебышёва. Для RBF, ансамбля и гауссовского процесса схема показывает значения компонентов для выбранного входа. График использует дискретную сетку, поэтому скачки кусочно-постоянных моделей изображаются с конечным разрешением.

## Устройство и проверки

- `src/data.rs` — данные, фаза и метрики.
- `src/model.rs` и `src/model/` — модели и типизированные параметры.
- `src/numerics.rs` — QR Хаусхолдера и разложение Холецкого. Решение систем выполняется без явного обращения матриц.
- `src/lab.rs` — состояние эксперимента, переобучение и диагностика.
- `src/ui/` — компоненты Leptos и SVG.

```sh
cargo fmt --all -- --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo clippy --locked --target wasm32-unknown-unknown -- -D warnings
```

Тесты сверяют стартовые числа с исходной лабораторией, проверяют все семь моделей на 200 точках, исключение выбросов, периодичность, интервалы GP и обучение Adam. Для ручной проверки интерфейса переключи метод, отметь выброс, включи исключение и запусти обучение нейросети. На стартовом наборе RMSE полинома округляется до 1,0815, а при включении сравнения с тестом отображается 0,82449.

## Кластеризация

Вкладка «Кластеризация» показывает k-means на 105 точках без меток. По умолчанию задано три центра. «Следующий шаг» чередует назначение ближайшего центра и перенос центров в среднее положение их групп. При изменении k точки сохраняются, а алгоритм запускается с начальных центров. «Начать заново» возвращает текущий набор к первому кадру, «Новые точки» меняет seed. После стабилизации назначений шаги останавливаются.

На тех же наблюдениях можно запустить иерархический single-link и DBSCAN. В single-link каждый шаг сливает две группы по ближайшей паре точек. DBSCAN проверяет очередную точку и расширяет группу, если её окрестность достаточно плотная. Радиус и минимум точек настраиваются отдельно, а переключатель редких точек позволяет показать шум.

## Обучение с подкреплением

Во вкладке доступны Q-learning, SARSA и DQN на одном детерминированном поле. Агент получает +1 в цели, −1 в ловушке и небольшой штраф за обычный шаг. Эпизод заканчивается в цели, в ловушке или после 96 ходов. Кнопки запускают один ход, остаток эпизода или следующие 100 эпизодов. Длительное обучение идёт порциями, и его можно остановить с сохранением пройденных ходов и весов. Смена метода или ε, просмотр маршрута и сброс останавливают текущий запуск. Оценки Q показывают ожидаемую дисконтированную награду за каждый ход. Просмотр маршрута использует жадный выбор без случайных действий и без обновления весов.

У методов отдельные состояния обучения. Настройка ε определяет вероятность случайного хода. Смена штрафа сбрасывает все методы, чтобы их оценки относились к одной схеме наград. DQN использует сеть с одним скрытым слоем ReLU с one-hot входом, буфер опыта и целевую сеть. Эта небольшая сеть демонстрирует механизм DQN на фиксированной карте.

Поле — 9×7. В блоке «Внутри агента» можно выбрать клетку и увидеть четыре оценки Q. Для Q-learning и SARSA отображается таблица состояний, для DQN — активный элемент one-hot входа, 24 активации ReLU и четыре выхода. Веса сети показаны для выбранного состояния, график использует онлайн-сеть. Начальная вероятность случайного хода — 45%: на более крупном поле агенту нужно чаще исследовать альтернативы.
